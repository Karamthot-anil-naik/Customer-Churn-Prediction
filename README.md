## 🚀 Project Overview

Customer churn is one of the biggest challenges faced by telecom companies. This project predicts customer churn using Machine Learning and provides an interactive web interface for making predictions on new customer data.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/karamthot-anil-naik/Customer-Churn-Prediction.git
```

Go to project folder

```bash
cd Customer-Churn-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
